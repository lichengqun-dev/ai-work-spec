## 为什么本目录只有一份"要点"

需求分析的**规范知识**（条目合格标准、功能点粒度、歧义处理、场景归类）是整个需求段共用的，
放在域级 `01_需求设计/references/`，由 `02-analysis` 主用、其他 Skill 按需读。
本目录只放**这一步骤自身的纪律**（为什么必须停下、编号纪律的代价），不复制域级规范——
复制一份等于制造一个会分叉的副本。

## 什么时候该在本目录新增文件

出现**只有这个 Skill 用得上**的知识时，例如：

- 该 Skill 特有的产出格式细则（不适用于同域其他 Skill）
- 该 Skill 的失败案例集
- 该 Skill 的历史调优记录

**判据**：同域其他 Skill 会不会用到？会 → 放域级 `references/`，不要在这里重复一份。
共用知识在每个 Skill 下各存一份，是知识库腐化的典型起点——改一处忘另一处。
