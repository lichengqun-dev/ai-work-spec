# 能力声明

把设计稿（Figma / Axure 导出物）转换为可运行的原型工程页面，并补齐 `data-fn` 标记。

## 输入契约

| 输入 | 来源 | 必需 | 校验规则 |
|---|---|---|---|
| 设计稿导出物 | 用户提供 | 是 | 可解析（Figma JSON / Axure HTML 导出 / 切图 + 标注） |
| 需求功能分析 | 02-analysis 产出 | 是 | 用于补齐 `FN` 标记 |
| 目标前端技术栈 | 生效规范快照 | 是 | 决定输出代码形态 |

## 产出契约

| 产出 | 路径 | 格式 |
|---|---|---|
| 原型页面 | 原型工程仓 | 与 `ai-requirement-03-prototype` 的产出同构 |
| 标记补齐说明 | 文档仓 `docs/01_需求/原型标记补齐说明.md` | 哪些元素无法自动映射到 `FN`，需人工确认 |
