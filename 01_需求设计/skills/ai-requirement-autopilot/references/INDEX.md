## 为什么这里没有独立知识文件

本 Skill **不做事**——调用顺序、门禁拦截、失败中止的规则全在 `SKILL.md` 里（它们是编排指令本身，
拆出去会让编排逻辑散成两处）。执行细节一律在**被编排的 Skill** 里，这里只留指针。

## 什么时候该在本目录新增文件

出现**只有这个 Skill 用得上**的知识时，例如：

- 该 Skill 特有的产出格式细则（不适用于同域其他 Skill）
- 该 Skill 的失败案例集
- 该 Skill 的历史调优记录

**判据**：同域其他 Skill 会不会用到？会 → 放域级 `references/`，不要在这里重复一份。
共用知识在每个 Skill 下各存一份，是知识库腐化的典型起点——改一处忘另一处。
