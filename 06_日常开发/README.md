# 日常开发

> 小需求快车道、热修、技术债、日常答疑。**P2 阶段交付。**

日常开发占研发团队 40%–60% 的实际工时。快车道的设计原则是：**允许跳步，但必须留痕。**

## 本域的 Skill

| Skill | 职责 | 说明 |
|---|---|---|
| [ai-daily-01-fastlane](./skills/ai-daily-01-fastlane/SKILL.md) | 小需求快车道 | 判定是否够格走快车道 → 准入检查 → 精简编码 → 轻量评审 → 台账登记。 |
| [ai-daily-02-hotfix](./skills/ai-daily-02-hotfix/SKILL.md) | 线上问题与热修 | 定位 → 复现用例 → 修复 → 补测试。 |
| [ai-daily-03-techdebt](./skills/ai-daily-03-techdebt/SKILL.md) | 技术债识别与排期 | 从快车道台账与故障案例中识别技术债，输出排期建议。 |
| [ai-daily-04-qa](./skills/ai-daily-04-qa/SKILL.md) | 基于知识库的日常答疑 | 检索生效快照与规范包，回答「这个字段为什么这么设计」这类问题。 |
