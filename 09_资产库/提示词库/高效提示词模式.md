# 高效提示词模式

> 沉淀在实战中验证有效与无效的提示词写法。**只记录有对比经验的内容，不要收录通用技巧。**

## 为什么需要它

Skill 的版本号修订位（`SKILL.md` 的 `metadata.version` 里的 Z）专门用于提示词优化。但如果优化经验不沉淀，
每次调优都是重新摸索，而且下一个人可能把有效的写法改回无效的。

## 待填充

按"场景 → 有效写法 → 无效写法 → 为什么"的结构记录。示例格式：

```markdown
## 场景：让模型按固定格式产出

**有效**：给出一个完整的填充示例（正例），再给一个格式错误的示例（反例）。
**无效**：只描述格式要求（"用表格输出，包含 A、B、C 列"）。
**原因**：描述性要求会被"合理理解"成各种变体；正反例给出的是可判定的边界。
```

## 注意

本文件记录的是**提示词写法**层面的经验，不是规范内容。规范内容属于规范包。
