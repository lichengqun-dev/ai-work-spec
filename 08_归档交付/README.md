# 08_归档交付

> 批次结项：产出物归集、索引更新、断链检测。

## 这个域有什么

| 内容 | 位置 | 说明 |
|---|---|---|
| 结项 Skill | `skills/ai-archive-01-close/` | 批次闭环的最后一步 |
| 结项报告模板 | `templates/批次结项报告模板.md` | — |

## 为什么要独立成域

归档是**独立的一个阶段**，不是"其他阶段的附属动作"。它承担三件别处不做的事：

1. **断链检测**（gate-06）——回答"这批产出物是不是一条完整的链"
2. **批次闭环**——把批次状态文件终态化，使其成为可审计的历史
3. **索引更新**——更新功能编号总表与文档索引，让追溯链对新批次持续可用

跳过归档的代价是**追溯链断在最后一步**：功能上线了，但没人能回答"它完整走完了哪些环节"。

## 产出物去向

```
<项目文档仓>/<需求名>/04_交付/
└── 结项报告.md          ← 批次概览、FR 清单、断链结果、豁免记录、遗留问题
```

其余落位：

| 产出 | 去向 |
|---|---|
| 终态化的批次状态文件 | 本仓库 `projects/<项目码>/.agent/state/<批次号>.yaml`——归档后**只读，不得删除**，追溯链依赖它 |
| 索引更新 | 本仓库 `projects/<项目码>/.agent/index/功能编号总表.md`（回填批次号列） |

**本域不修改任何产出物内容**，只核对存在性与哈希。断链未清零时**不自动补链**——
补链意味着补文档，那是人的工作。
