# 执行日志

本目录存放 Skill 执行的**元数据**日志，不存放思维链。

| 文件 | 内容 |
|---|---|
| `spec-build.jsonl` | `ai-spec-build` 每次构建追加一行 |
| `<批次号>.jsonl` | 批次内各 Skill 的执行记录（P1 起） |

## 为什么只记元数据

**产出物才值得存档，中间推理不值得。** 日志的用途是排查"这次执行发生了什么异常"，
以及回答"这个批次当时用的是哪版规范"——这两件事靠时间戳、哈希、状态就够回答。

记录思维链会带来三个问题：体积膨胀、包含不该留存的内容、以及没人会去读。

## 格式

JSON Lines，每行一个 JSON 对象。字段见各 Skill 的产出契约。

`.ai/logs/` 可以清理（保留最近 N 个月），但 `.ai/state/` 下已归档批次的状态文件**不可删除**——
追溯链依赖它。
