# 产出模板

存放 工程骨架、单测、提交信息等产出模板。

## 使用方式

Skill 执行时**读 references 学怎么做，套 templates 写出结果**。

这也是 `templates/` 与 `references/` 分开的原因：

| 目录 | 内容 | 性质 |
|---|---|---|
| `templates/` | 待填的**空壳**（文档骨架） | 抄 |
| `references/` | 已填满的**范本与规则** | 学 |

混在一起会导致 Skill 分不清哪个是学、哪个是抄。

## 模板的写法要求

1. **每个结构单元留出编号位置**（如 `FN-XXX-001`），因为产出物必须携带编号
2. **关键位置带填写说明**（用 `<>` 或注释标出"这里要写什么"），不要留空
3. **可判定的项给出格式示例**，如验收要点写"导出 1 万条耗时 ≤ 30 秒"而非"性能良好"
