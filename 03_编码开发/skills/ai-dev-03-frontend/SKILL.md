# ai-dev-03-frontend · 前端实现

## 能力声明

依据**冻结契约**与前端设计实现前端页面，从原型工程迁移，基于契约联调。

技术细节从生效规范快照读——换技术栈不需要重写本 Skill。

**不做什么**：不改契约、不改原型、不做后端实现、不做视觉设计、不重构与当前 FN 无关的页面——见「边界」。

## 何时用 / 何时不用

- **用**：工程骨架与前端设计就位、契约冻结，要把原型落成前端实现并对接接口时
- **不用**：原型本身要改（回到 `ai-requirement-03-prototype`）；只补单元测试（走 `ai-dev-04-unittest`）；
  联调发现契约不够用（先开变更子批次，不是继续写页面）

## 输入契约

| 输入 | 来源 | 必需 | 校验规则 |
|---|---|---|---|
| 接口契约 | `ai-design-04-api` 产出 | 是 | **冻结态**；哈希须与记录一致 |
| 前端设计 | `ai-design-05-frontend-spec` 产出 | 是 | 含页面清单、组件拆分、状态流转、接口映射 |
| 原型工程 | `ai-requirement-03-prototype` 产出 | 是 | 带 `data-fn` 标记 |
| 生效规范快照 | `projects/<项目码>/.agent/spec-effective/<项目码>.md` | 是 | 前端规范与组件约定的唯一来源 |

## 产出契约

| 产出 | 路径 | 格式 |
|---|---|---|
| 前端代码 | 项目代码仓 | 按 FN 分次提交，提交信息含 FN 编号 |

前端**按页面交付更自然**——一个页面对应多个 FN 是常态，但提交信息仍须带 FN 编号：

```
feat(FN-CORE-045): 列表页导出入口与结果展示

覆盖 FN-CORE-045（导出入口）、FN-CORE-046（导出结果下载）
```

## 前置条件

**hard（不满足则拒绝执行）**

- 接口契约已产出且**处于冻结态**，其**哈希与记录一致**
- 前端设计已产出，页面与接口的映射关系明确
- 原型工程可读，且页面带 `data-fn` 标记
- 生效快照中的前端规范包存在

**soft（不满足则提示，可继续）**

- gate-03 设计评审已通过（未通过时产出物标注"未经评审"）

## 执行步骤

1. 从原型工程**迁移**页面结构（迁移而非重画），保留布局骨架与交互模式
2. 按前端设计的组件拆分重组；查组件清单决定复用还是新建
3. 按前端设计的接口映射接入契约中的接口
4. 应用前端设计标注的状态归属（服务端状态用请求层管理，**不进全局 store**）
5. 补齐异常态与空态的呈现（三种态按设计统一处理，不要三个页面三种做法）
6. 提交，提交信息格式：`feat(FN-XXX-000): <描述>`；一个提交覆盖多个 FN 时在 body 中列全
7. 下一个页面或 FN
8. 回写批次状态文件：本步骤置 `done`，记录本次实现的页面与 FN 清单

迁移路径：

```
原型页面（带 data-fn 标记）
  → 按前端设计的组件拆分重组
  → 接入契约中的接口
  → 补异常态与空态
```

### 技术细节从快照读

你的 prompt 里没有框架写法，这是刻意的：

| 你要做的事 | 该读的条目 |
|---|---|
| 写组件 | `STD-VUE3-*` / `STD-REACT-*` 的组件写法条目 |
| 发请求 | `STD-BASE-412` + 对应前端包的请求封装条目 |
| 写文案 | `STD-VUE3-004`（国际化）或 `STD-BASE-413` |
| 写表单 | 对应前端包的校验条目 |

状态管理写法（Pinia / Vuex / 自建 hook）同样从生效快照读。

**快照没覆盖的细节，停下来问。**

## 独立执行

- **hard 全满足即可单独运行**，不必从流程第一步开始——接一个页面就能跑
- soft 不满足时照常产出，并在产出物顶部标注「未经上游确认 —— <哪一条没满足>」
- 批次状态文件不可写（未接入批次）时：产出物落到指定路径、跳过状态回写并在报告中说明

## 边界（明确不做）

- **不改契约。** 联调发现接口不够用 → 停止并说明需要变更子批次
- 不改原型、不修改原型工程（原型是已确认的形态，改动需回到 `ai-requirement-03-prototype`）
- 不做后端实现（`ai-dev-02-backend`）
- 不做视觉设计（配色、图标、动效）——除非前端设计明确要求
- 不重构与本 FN 无关的页面
- **不把服务端状态塞进全局 store**
- 不自行决定快照未覆盖的组件用法
- 不执行 git 操作

## 失败处理

| 失败情形 | 处理 |
|---|---|
| 契约哈希不一致 | **停止**，报告契约被改动过 |
| 原型中某页面缺 `data-fn` 标记 | 列出，回到 `ai-requirement-03-prototype` 补齐，**不凭印象实现** |
| 契约字段不足以支撑页面 | 停止并说明需要变更子批次 |
| 快照未覆盖的组件用法 | 停下问用户，**不自行决定** |
| 需要引入新的前端依赖 | 停止并说明，走确认流程 |

## 输出格式

```

对应 FN：FN-CORE-045、FN-CORE-046
原型来源：原型工程 pages/list.vue（data-fn: FN-CORE-045/046）

接口接入：POST /api/v1/export、GET /api/v1/export/{id}

提交：feat(FN-CORE-045): 列表页导出入口与结果展示
待确认：无

下一个页面：详情页（PAGE-CORE-004）
```
