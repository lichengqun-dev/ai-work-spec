## 最值得新增的知识文件

**契约片段范本**：把团队约定的写法固化成可直接复制的片段，比描述性要求有效得多。例如：

- 统一响应包（`{code, data, message}`）的 schema 片段
- 统一错误结构 + 错误码段落的写法
- 分页请求 / 分页响应的 schema 片段
- `x-fn-id` 与 `x-error-codes` 扩展字段的用法

**原因**：描述性要求（"错误码要完整"）会被"合理理解"成各种变体；
片段范本给出的是可判定的边界。
