## 为什么这里几乎没有方言知识

数据库设计的绝大部分规则是**方言相关**的（CLOB 读取、空串与 NULL 是否等价、模式名大小写敏感、
`CONCAT` 参数个数），所以它们属于规范包而不属于本 Skill。
把方言知识抄一份到这里，等于制造一个会过期的副本——而且要命的是，**它错了不会报错，只会让 SQL 语义悄悄偏掉**。

## 什么时候该在本目录新增文件

- 本项目的表命名与字段类型约定（若与包内约定有项目特有的补充）
- 分库分表 / 归档策略（若项目有这类需求）
- 历次 DDL 变更的事故复盘
