# 门禁检查脚本

存放 `gates/*.md` 中标注 `方式=auto` 的检查项的脚本实现。

## 命名约定

脚本名与门禁编号对应：`gate-01-*.sh` / `gate-03-*.py` 等，便于 `ai-gate-runner` 按门禁定位。

## 硬性要求

1. **退出码语义统一**：`0` = 通过；`1` = 检查未通过；`2` = 脚本自身出错（配置缺失等）。
   `2` 不能被当成"通过"——脚本执行失败和检查失败是两件事。
2. **输出必须可定位**：失败时打印具体对象（哪个 FN / 哪个接口 / 哪个文件），
   不能只打印"检查未通过"。
3. **幂等且只读**：脚本不修改被检查的对象，可以重复执行。

## 目前为空

P0 阶段门禁靠人工按清单核对。脚本实现随 `ai-gate-runner` 在 P1 交付。
