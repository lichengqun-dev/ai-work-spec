# 知识索引 · ai-gate-runner

**本 Skill 目前没有独立的知识文件。** 它执行时所需的知识见对应域的 `README.md` 与
`00_工作空间配置/` 下的规范。

## 什么时候该在本目录新增文件

当出现**只有这个 Skill 用得上**且**篇幅较大**的知识时（范本、细则、清单、历史案例）。

**判据一**：同域其他 Skill 会用到吗？会 → 放域级，不要在这里重复一份。
**判据二**：能写进 `prompt.md` 吗？能且不超过预算 → 写进 prompt.md，不要单独建文件。

共用知识在多个 Skill 下各存一份，是知识库腐化的典型起点——改一处忘另一处。
