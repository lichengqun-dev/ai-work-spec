## 为什么这里几乎没有领域知识

本 Skill 只判定路径、写状态文件，**不碰业务内容**。它需要的领域知识（需求条目怎么写、功能点粒度、
场景怎么归类）属于整个需求段共用，放在域级 `01_需求设计/references/`——按上表的知识库根相对路径读。

## 什么时候该在本目录新增文件

出现**只有这个 Skill 用得上**的知识时，例如：

- 该 Skill 特有的产出格式细则（不适用于同域其他 Skill）
- 该 Skill 的失败案例集
- 该 Skill 的历史调优记录

**判据**：同域其他 Skill 会不会用到？会 → 放域级 `references/`，不要在这里重复一份。
共用知识在每个 Skill 下各存一份，是知识库腐化的典型起点——改一处忘另一处。
