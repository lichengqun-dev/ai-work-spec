## 什么时候该在本目录新增文件

- 测试报告的历史范本（好的与不好的各存一份，对比比规则有效）
- 遗留风险的表述方式（怎么把"未做的部分"写得具体而不含糊）
- 历次"报告说没问题，上线后出问题"的复盘

**最后一类值得认真记**：它会指向两种可能——报告美化了数据，或者测试范围本身有盲区。
两者的修法完全不同。
