## 为什么本目录只有一份"要点"

本 Skill 的**产出结构**由 PRD 模板定义，**事实来源**是原型工程，**领域规范**在域级与 `standards/`。
把模板抄一份到这里，等于制造一个会与模板分叉的副本；而 PRD 是下游所有设计的输入，分叉的代价最大。

## 什么时候该在本目录新增文件

出现**只有这个 Skill 用得上**的知识时，例如：

- 历次"PRD 与原型不一致"的复盘（哪类不一致最容易发生）
- 验收要点的写法范例集（可判定 vs 不可判定）
- 读原型提取标记时踩过的坑（元素嵌套、动态渲染、条件渲染）

**判据**：同域其他 Skill 会不会用到？会 → 放域级 `references/`，不要在这里重复一份。
共用知识在每个 Skill 下各存一份，是知识库腐化的典型起点——改一处忘另一处。
