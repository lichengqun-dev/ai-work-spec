**默认只加载本文件。** 本 Skill 是编排层，它不需要领域知识——领域知识在被编排的 Skill 里。

## 什么时候该在本目录新增文件

- 路径判定的**歧义案例**（"这种情况算新建还是迭代"）——这类判断最需要靠案例而不是规则
- 历次编排中发现的**接缝问题**（某两步之间的产出物对不上、某道门禁的产出方缺失）

**第二类尤其值得记**：2026-10-20 的端到端演练发现，这类体系的卡点几乎全部落在
**Skill 之间的缝里**，而不是单个 Skill 内部。编排层是最先撞上这些缝的地方。

## 不要在这里复制什么

- **不要复制各 Skill 的职责说明。** 那些写在各自的 `SKILL.md` 里；
  复制一份到这里，改动时必然只改一处
- **不要复制门禁的检查项。** 那些在 `07_质量门禁/` 下
