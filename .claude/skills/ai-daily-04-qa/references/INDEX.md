# 知识索引 · ai-daily-04-qa

> `references/` 默认**只加载本文件**。按下方「何时读取」按需读取，单次不超过 3 个文件、合计 1500 行。
> **本文件内的路径**：`references/` 开头的是本 Skill 内的资源；「知识库根下」开头的是 Skill 之外的资源。

| 知识 | 位置 | 何时读取 |
|---|---|---|
| 答疑要点（为什么"找不到"最有价值、分歧怎么处理、只读纪律） | `references/答疑要点.md` | 找不到答案、或遇到互相矛盾的内容时 |
| **检索顺序** | 本 Skill 的 `SKILL.md`「检索顺序」节 | **按它找，不要跳** |
| 设计理由 | 知识库根下 `README.md`（机制层面的问题——为什么这么设计、哪些取舍是刻意的） | 问到机制设计时 |
| 规范包来源链 | 生效快照的 C 段（"这条规则是谁定的、被改过几次"） | 追"为什么是这样"时 |
| 项目约定 | 知识库根下 `projects/<项目码>/.agent/memory/项目约定.md`（尚未稳定为规范的共识） | 问到项目特有约定时 |

## 什么时候该在本目录新增文件

- 高频问题的标准答案（避免每次重新检索）
- 历次"找不到"的问题及它们最终记到了哪里

**最后一类是本 Skill 最有价值的沉淀**：它把"知识库的缺口"变成了可跟踪的清单，
而这些缺口决定了下一步该往知识库里补什么。
