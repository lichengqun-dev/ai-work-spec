# <项目名> 项目特有规范

> 本文件只记录**这个项目独有**的约束。
> 任何在 `09_资产库/规范包/` 或各域 `standards/` 里已有的内容，这里**只写引用不写正文**。

## 什么时候该写在这

- 这个项目独有的业务规则
- 这个项目独有的外部约束（部署环境、客户指定的工具链）
- 这个项目特有的历史包袱（如"仍有 3 个模块在用计划移除的老组件库"）

## 什么时候不该写在这

| 情况 | 应该放哪 |
|---|---|
| 跟技术栈有关 | 对应的 `stacks/*` 包 |
| 跟业务领域有关 | 对应的 `domains/*` 包 |
| 所有项目都适用 | 各域 `standards/` 基线 |
| 只在本批次有效 | 批次状态文件 `.ai/state/<批次号>.yaml` |

## STD-PRJ-<项目码大写>-001 · 示例：所有对外接口必须携带隔离标识

<!-- meta
tier: resident
scope: 接口开发
frozen: false
-->

**规则**：所有对外接口的查询条件必须携带隔离标识（如 `tenant_id`），禁止跨隔离域聚合查询。

**正例**：`mapper.selectByTenant(tenantId, condition)`

**反例**：`mapper.selectAll(condition)`

**原因**：本项目是多租户形态，跨租户查询等同于数据越权。ORM 层不强制该条件，必须靠约定与评审保证。

**例外**：运维后台的跨租户统计接口，需走独立的鉴权入口。
