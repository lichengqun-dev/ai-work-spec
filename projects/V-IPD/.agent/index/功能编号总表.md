# 功能编号总表

## 使用方式

| 场景 | 动作 |
|---|---|
| 新增需求条目 | 在「需求条目」段追加 `REQ-<模块码>-<三位>`，序号取该模块当前最大值 +1 |
| 新增功能点 | 在「功能点」段追加 `FN-...`，`来源 REQ` 列必填 |
| 功能行为修改（迭代） | 新增 `FN-<原编号>-D<n>`，不修改原条目 |
| 归档批次 | 填写「批次」列，供 gate-06 断链检测 |
| 编号废弃 | 保留行，状态列改 `[已废弃]`，**不回收编号** |

**编号一经启用不复用。** 删除条目时保留编号并标记，不回收——回收会让历史文档中的引用指向错误的对象。
