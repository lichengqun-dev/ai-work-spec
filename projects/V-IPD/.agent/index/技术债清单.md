## 条目格式

```markdown
### TD-001 <位置/模块>

**依据**（必须是数字）
- 快车道台账：近 N 天改动 M 次
- 故障复盘：N 次（编号）
- 缺陷台账：缺陷占比 X%
- 依赖关系图：被 N 个 FN 依赖

**问题判断**：……

**影响面**：……

**建议处置**：……

**优先级**：高 / 中 / 低
```

## 采集阈值（可调，但必须有阈值）

| 信号 | 判据 |
|---|---|
| 高频改动 | 同一 FN 30 天内改动 ≥5 次 |
| 反复出问题 | 同一模块 60 天内故障 ≥2 次 |
| 缺陷集中 | 某模块缺陷占比 > 25% |
| 改动风险高 | 被 ≥10 个 FN 依赖 |

**没有阈值的"高频"和"集中"都是主观判断**，而主观判断排不进计划。
