# 指令：一比一复刻现系统（UAT）页面

## 你要做的事

把现系统（UAT）的一个页面/组件**一比一**复刻到新实现里。**六步缺一不可**，顺序也不能换。

## 铁律：代码与页面必须互证

**不许只看页面不读代码，也不许只读代码不看页面。** 只看页面会漏掉源码里的 class 层级与样式来源；
只读代码会漏掉主题/全局样式的运行时覆盖。

## 六步（照 SKILL.md 执行，这里只列不能省的点）

1. **源码定位**：先读老代码。按 URL 找页面 → 读 SFC 的 template 结构（**class 命名要照抄**）+ 它 import 的 SCSS（**样式文件必须一起读**）→ 读老后端接口 → 动态表单页另查模板映射
2. **UAT 实测**：用 DOM 快照拿结构、用 `getComputedStyle` 拿**计算样式**（比截图精确）、下载静态资源、存同视口截图
3. **双向互证**：源码值与运行值不一致（主题覆盖）时，**以运行值为准**，但在注释里注明源码出处
4. **实现**：结构照抄、样式逐项对齐、**Element UI → Element Plus 的已知差异必须主动覆盖**（对照表在 SKILL.md，逐项查）
5. **验证**：同视口截图交视觉模型做**找茬式**对比（要求列出最细微差异：字重/间距/颜色），交互回归跑一遍
6. **记录**：追加 `docs/重构日志.md`；**新发现的差异点补回对照表**（本 Skill 是活文档）

## 两个精度更高的方法（比截图 diff 准）

- **计算样式提取**：`getComputedStyle` 逐元素取布局/颜色/字体/圆角/阴影/层级
- **几何验证法**：两边各自 `getBoundingClientRect()` 取卡片内元素相对坐标（x,y,w,h），**对比到像素级**

## 安全红线

- 登录密码等敏感字段**禁止明文传输**（现行方案：前端 jsencrypt + RSA 公钥）
- **UAT 只读**：禁止创建/修改/删除任何数据；退出登录等会话操作允许

## 你绝对不要做的事

- **不要用 Element Plus 的默认图标替代现系统图标**——形状不同，视觉对比会一眼看出
- **不要在"看起来一样了"时收工**——第 5 步的找茬对比没过就不算完
- **不要跳过第 6 步的记录**——复刻中发现的差异点不写下一次还要再踩一遍
- 不要执行 git 操作

## 输出格式

```
页面：<页面名>
第 1 步 源码定位：<老前端路径> / <涉及的老后端接口>
第 2 步 UAT 实测：DOM ✅ / 计算样式 ✅（N 个元素）/ 资源 ✅ / 截图 ✅
第 3 步 双向互证：一致 / 不一致 N 处（以运行值为准，已注明出处）
第 4 步 实现：结构照抄 ✅ / EP 差异覆盖 N 项
第 5 步 验证：视觉找茬第 1 轮 → N 处差异 → 修 → 第 2 轮 ✅ 一致
第 6 步 记录：docs/重构日志.md 已追加；对照表新增 N 条
```
