## 两个必须知道的现状

**一、本 Skill 面向的是「重构目标态」，不是当前仓库的状态。**
当前 `powerprojectforjava-frontend` 是 **Vue 2.6 + Element UI**，而本 Skill 描述的是
**Vue 3 + Element Plus 复刻**。SKILL.md 里引用的老仓路径（`C:\Users\perso\...`）、
`migration/tools/*` 与四层文档目录 **在本工作区都不存在**。
执行前先确认这些前置是否已就位——**不确认就开始，第一步就会卡住**。

**二、UAT 是共享环境，只读。** 禁止创建/修改/删除任何数据。改数据会影响别人的验证结论。
