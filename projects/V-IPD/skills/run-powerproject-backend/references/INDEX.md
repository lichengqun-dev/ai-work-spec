## 什么时候该在本目录新增文件

当出现**只有启动这件事才用得上**的知识时。例如：

- 某台具体机器上的启动故障（路径、JDK 安装位置差异）
- pathing.jar 生成失败的具体形态与修法

**判据**：`run-pp-extend` / `debug-full-stack` 会不会用到？会 → 放域级（`projects/V-IPD/` 根）。
共用知识在每个 Skill 下各存一份，是知识库腐化的典型起点——改一处忘另一处。
