## 1. 概述

在 V-IPD 的任务模块上新增**点检任务**能力：原始任务未完成时按配置周期自动生成点检任务，
点检人也可手动发起；责任人反馈后进度与说明回写原始任务；原始任务详情页新增「点检任务」页签；
反馈进度 100% 触发原始任务关闭。

**不改造**原始任务现有页面逻辑、其他页签与低码配置部分。

**原型结构**：4 个页面 + 2 个弹窗，覆盖 24 个 `FN`。

| PAGE | 页面 |
|---|---|
| `PAGE-TASK-001` | 工作台任务列表 |
| `PAGE-TASK-002` | 原始任务详情页（含「点检任务」页签、生成点检任务弹窗） |
| `PAGE-TASK-003` | 点检任务详情页 |
| `PAGE-TASK-004` | 任务反馈弹窗 |

## 2. 功能逐条说明

### FN-TASK-001 · 定时扫描未完成的原始任务并判定到期

| 项 | 内容 |
|---|---|
| 功能描述 | 服务端按扫描频率取出未完成的原始任务，计算「计划开始 + N × 生成间隔」，到期即生成下一轮。无界面 |
| 入口 | 无（后端定时任务） |
| 交互说明 | 无可交互界面。对使用者的可见表现是：**原始任务详情页「点检任务」页签里不断出现「自动」来源的新任务** |
| 字段说明 | — |
| 异常提示 | 原始任务已完成 → 跳过；计划时间为空 → 跳过并记日志 |
| 验收要点 | 间隔 7 天、原始任务计划开始 10-01 → 10-08 / 10-15 / 10-22 各生成一条；任务完成后不再生成 |

### FN-TASK-002 · 生成点检任务并继承字段

| 项 | 内容 |
|---|---|
| 功能描述 | 按继承规则建立点检任务；**创建人取原始任务的点检人**（不写「系统」） |
| 入口 | 自动生成 / 「生成点检任务」按钮 |
| 交互说明 | 页面上表现为点检任务详情页的信息栏显示继承来的字段 |
| 字段说明 | 责任人 / 关联阶段 / 项目角色 / 任务类别 / 关联项目 / 路径信息 继承原始任务；**创建人 = 原始任务点检人**；进度默认带出原始任务当前进度；点检时间、点检人**不继承、不展示** |
| 异常提示 | 点检人为空 → 不生成并记日志（创建人取不到值，且点检人是权限主体） |
| 验收要点 | 点检任务详情页「创建人」显示为点检人本名，**不是「系统」** |

### FN-TASK-003 · 计算点检任务的计划时间

| 项 | 内容 |
|---|---|
| 功能描述 | 计划开始 = 原始任务计划开始 + 生成间隔；计划完成 = 计划开始 + 完成偏移 |
| 入口 | 无（随生成计算） |
| 交互说明 | 页面上表现为「点检任务」页签的「计划开始 / 计划完成」两列 |
| 字段说明 | 实际开始 / 完成时间：生成时为空，反馈时填写 |
| 异常提示 | 算出的计划开始晚于原始任务计划完成 → 不生成 |
| 验收要点 | 间隔 12 天、偏移 3 天、原始任务计划开始 10-01 → 点检任务计划开始 10-13、计划完成 10-16 |

### FN-TASK-004 · 短周期任务的边界判定

| 项 | 内容 |
|---|---|
| 功能描述 | 跨度小于等于生成间隔时不生成点检任务 |
| 入口 | 无（后端判定） |
| 交互说明 | 无可交互界面 |
| 字段说明 | — |
| 异常提示 | 计划时间只有一个有值、或完成早于开始 → 跳过并记日志 |
| 验收要点 | 1 号开始 8 号结束、间隔 7 天 → **不生成**；1 号开始 9 号结束 → 生成 |

> ⚠️ **阈值口径待确认（Q-01）**：PRD 建议 `(计划完成 − 计划开始) > 生成间隔`。
> 等于间隔时是否生成、是否需要宽限，未定。

### FN-TASK-009 · 反馈表单的字段与校验

| 项 | 内容 |
|---|---|
| 功能描述 | 点检任务责任人提交进展 |
| 入口 | 任务反馈弹窗 |
| 交互说明 | 表单分两行排布；进度输入框即时校验并标红提示 |
| 字段说明 | 实际开始时间（必填，日期）／实际完成时间（选填，日期）／进度（必填，整数 1~100，默认带出原始任务当前进度）／是否有风险（选填，是/否，默认否）／进度说明（必填，文本） |
| 异常提示 | 「进度只能填写 1~100 的整数」；实际开始时间未填、进度说明未填 → 不允许保存 |
