## 一、库表全景（607 张表，按前缀分域）

## 二、一期核心模型（项目管理域）

### 2.1 项目主链路

```
pp_classification（项目分类，挂阶段/角色/状态配置）
   └─▶ pp_project（项目主表，55 列）
        ├─ pp_project_plan（项目计划，is_main_plan_ 主计划/交付物计划）
        │     └─ pp_task（任务，58 列，树形 first_child_id_/next_brother_id_）
        │           ├─ pp_task_assignment（任务分配）
        │           ├─ pp_task_link（任务依赖/前后置）
        │           └─ pp_plan_baseline(_task...)（基线快照）
        ├─ pp_project_member（成员，挂 pp_project_role）
        ├─ pp_project_budget(_expense/_labor/_material...)（预算）
        ├─ pp_project_doc / pp_document（文档，38 列，含工作流字段）
        └─ pp_todo / pp_todo_done（待办/已办，44 列，含 bpm_* 关联字段）
```

### 2.2 关键表字段（实测）

**pp_project**（dev 库 326 行）：
- 标识：`id_`、`code_`、`name_`、`pinyin_`、`short_name_`
- 归属：`pp_parent_id_`（父子项目）、`classification_id_`、`state_id_`、`grade_id_`、`template_id_`、`org_id_`
- 计划：`start_/finish_/actual_start_/actual_finish_`、`baseline_*`（基线三件套）、`progress_/planned_progress_/baseline_progress_`、`duration_/duration_days_`
- 状态灯：`light_`（红绿灯）、`light_description_`
- 岚图定制：`software_platform_`、`hardware_platform_`、`vehicle_model_series_`、`sop_time_`、`zhuan_ye_`（专业）
- 通用：`tenant_id_/ip_/create_by_/create_time_/update_by_/update_time_/deleted_/version_`

**pp_task**（树形结构，不用 parent_id 而用兄弟链）：
- `first_child_id_` + `next_brother_id_` 组成树（首孩子/下一兄弟链表）
- `is_milestone_`、`is_critical_`（关键路径）、`is_schedule_lock_`
- `schedule_state_`、`approval_state_`、`state_`
- `assignee_ids_`、`approver_ids_`、`informer_ids_`（多值逗号串）
- `flow_def_id_`（挂 BPMN 流程定义）

**pp_todo**（待办，业务事件驱动写入）：
- `object_type_`/`object_id_`（待办挂的业务对象）
- `bpm_task_id_`/`bpm_inst_id_`/`bpm_node_name_`（BPMN 关联）
- `user_id_`（待办人）、`task_state_`、`has_read_`/`has_done_`
- 项目冗余：`project_id_/project_name_/project_code_/project_short_name_`
- 同步：VHome（`pp_vhome_todo_sync_log`）

### 2.3 一期通用字段约定（pp_* / iform_* 表）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id_` | varchar(64) | 主键（雪花/UUID） |
| `tenant_id_` | varchar(64) | 租户 |
| `create_by_` / `update_by_` | varchar(64) | 操作人 |
| `create_time_` / `update_time_` | timestamp | 时间 |
| `deleted_` | varchar(20) | 逻辑删除 'N'/'Y'（**查询必须带 `deleted_='N'`**） |
| `version_` | numeric | 乐观锁 |

## 三、二期核心模型（extends_ 域，按服务分）

### 3.1 performance（性能指标）——版本快照模式

```
extends_template_performance_target_set（模板指标库）
   └─ extends_car_performance_target_set（车型指标主表，dev 8 行）
        ├─ status 状态机：1草稿→2目标设定→3目标冻结→4开发进行中→5验收中→6已验收
        ├─ source_template_set_id/...（来源模板追溯）
        ├─ source_template_snapshot jsonb（模板快照）
        ├─ _versions（版本表）→ _version_items → _version_item_plan_values
        ├─ _items（指标明细）→ _item_plan_values（配置×阶段计划值）
        ├─ _configs（车型配置）→ _config_stages（阶段）→ _config_stage_versions（快照）
        ├─ _competitor_relation（竞品对标关联）
        ├─ _stage_results（阶段实绩）→ _stage_result_versions / _stage_result_files
        └─ _tasks（指标关联任务）→ _task_rel_items
```

### 3.7 二期通用字段约定（extends_ 表）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | varchar(32) | 主键（MyBatis-Plus assign_id） |

## 四、核心业务流程

### 4.1 登录链路

```
前端 → oauth(6200) /oauth2/v3/user/captcha → 登录 → token 写 Redis db3
     → 后续请求带 token → 各服务从 db3 读 token context 校验
本地：GatewayFilter disable=true（vue proxy 无网关密钥头）
```

### 4.2 项目立项 → 计划 → 任务执行

```
pp_project_create（立项申请）→ 审批 → pp_project 落库
  → pp_project_plan（主计划）→ pp_task 树（甘特编辑）
  → pp_task_assignment 分配 → pp_todo 生成待办
  → 进度回填 progress_ → 红绿灯 light_ 预警
  → pp_plan_baseline 基线对比
```

### 4.3 二期业务通用模式（以 performance 为例）

```
模板库（template_*）→ 引用生成车型实例（car_*，记录 source_template_* + snapshot）
  → 编辑（草稿）→ 目标设定 → 冻结（lock_version 乐观锁）
  → 版本化（_versions 快照）→ 阶段验证（_stage_results）→ 验收
  → 变更走 BPMN（integration-layer 调一期流程）→ 飞书通知
```

### 4.4 待办/消息链路（两期共用）

```
业务事件（一期 BPMN / 二期服务）→ RabbitMQ → 消费写 pp_todo
  → VHome 同步（pp_vhome_todo_sync_log）→ 飞书消息推送（二期 cmf/competitor/specialised-parts）
```

## 五、跨域关联关系（对账/联查时用）

| 关联 | 字段 | 说明 |
|------|------|------|
| 二期业务 ↔ 一期项目 | `extends_*.project_id`/`project_no`/`project_code` | 二期表冗余存一期项目编号（部分存 project_name） |
| 二期 ↔ 一期待办 | integration-layer `TodoApi`/`BusinessTaskTodoSyncSdk` | 不直接写 pp_todo，走 MQ 同步 |
| 二期 ↔ BPMN | `extends_dvp_process.task_id`/`instance_id`、`flow_def_id_` | DVP/专用件变更挂 Activiti |
| 专用件 ↔ DVP | `extends_part_special_part_new.dvp_no` | 零件关联验证计划 |
| 性能 ↔ 竞品 | `extends_car_performance_target_set_competitor_relation` | 指标对标竞品车 |
| 体验 ↔ 性能 | `extends_experience_performance_relation`、`extends_template_experience_performance_relation` | 指标关联 |
| 文档 ↔ 工作流 | `pp_document.workflow_definition_id_`/`workflow_id_`/`simpleflow_id_` | 文档审批 |
