## 一、测试目标

验证 V-IPD 核心链路的功能正确性，为后续 AI 主导开发建立回归基线：

1. 登录认证链路（oauth + Redis db3）
2. 一期项目管理核心 CRUD（项目/计划/任务/待办）
3. 二期 7 服务核心接口可用性
4. 两期集成链路（integration-layer、待办同步）
5. 逻辑删除守卫（查询不返回已删数据）

## 三、数据对账方法

```python
# psycopg2 连测试库，查行数与接口返回 total 比对
SELECT count(*) FROM pp_project WHERE deleted_='N';            -- 一期
SELECT count(*) FROM extends_dvp_process WHERE is_deleted=1;   -- 二期（注意值域）
```

- 接口 total vs DB count 一致 → PASS
- 写操作后 `SELECT` 新行，校验 `create_by_`/`create_user_id`、`deleted_`/`is_delete` 值
- 测试数据前缀 `V-IPD-TEST-`，测完逻辑删除
