### 4.5 关键配置要点

1. **Redis 必须用 db3**（一期 `application-local-base.yml` 两处 `database` 为 3；二期 7 个模块 `application-local.yml` 默认值已从 db9 统一改为 db3，2026-10-09 修订，无需手动改）
2. **GatewayFilter 关闭**：`client.gateway.disable: true`（否则 vue proxy 直连报"非法请求" 6010101）
3. **Ribbon 静态路由**：服务间 Feign 走 `listOfServers: localhost:<端口>`（不走 Nacos discovery）
4. **改配置后必须同步到 target/classes**（jar 是旧构建打的，新配置不在里面）

### 4.6 内存策略（16GB 机器必读）

- Java 默认堆 = 物理内存 1/4 = 4GB/服务，12 服务 × 4GB 必挂
- **必须加 `-Xmx`**：一期 `-Xmx512m`，二期 `-Xmx256m`
- 不要同时启动 12 Java + 前端首编译
- 内存不足：先停 Java，等前端编译完（`http://localhost:9528/` 返回 200）再起 Java

### 4.7 启动步骤

完整启动步骤见 `./skills/run-powerproject-backend/SKILL.md`（本目录内），要点：

1. **JDK 8**（`C:\Program Files\Java\jdk1.8.0_491`），不要用默认 JDK 17
2. 每模块先 `mvn dependency:build-classpath` 生成 `cp.txt`，再用 PowerShell `New-PathingJar` 函数生成 `pathing.jar`（JDK 8 不支持 `@argfile`，classpath ~60KB 超命令行限制）
3. 同步配置到 `target/classes`
4. `java -Xmx512m -cp pathing.jar <主类>`，`SPRING_PROFILES_ACTIVE=local`

## 六、常见错误速查

| 症状 | 原因 | 解决 |
|------|------|------|
| 登录报"非法请求"（6010101） | GatewayFilter 拦截 | `application-local-base.yml` 加 `client.gateway.disable: true`，同步到 target/classes 重启 |
| 全部 Java 进程无声挂掉 | OOM（12 服务 × 默认 4GB 堆） | 加 `-Xmx512m`/`-Xmx256m` |
| 前端编译卡死/HTTP 000 超时 | 内存不足 | 停 Java，等前端编译完再起 Java |
| `找不到或无法加载主类` | pathing.jar manifest 有 BOM，或目录条目缺尾部 `/` | 重新生成（`UTF8Encoding($false)`，目录条目以 `/` 结尾） |
| `Mapped Statements collection does not contain value` | JDK 17（JAXB 缺失）或删了 `dataSource-platform-local.xml` | 换 JDK 8；恢复平台数据源 |
| `Port XXXX is already in use` | 进程没退干净 | `Get-Process java \| Stop-Process -Force` |
| 二期 dvp/experience 端口冲突 | 两模块都写 18083 | experience 已改 18082，勿改回 |
| `Unable to connect to Redis server: localhost:6379` | 共享配置没复制到 target/classes | 执行配置同步步骤 |
| Feign `Load balancer does not have available server` | Nacos discovery 关了但没配 Ribbon listOfServers | 确认 `application-local-base.yml` Ribbon 静态路由在 target/classes |
| `REQUEST_408` 应用 redis 与认证中心 redis 不是同一个 | local Redis database ≠ dev 的 db3 | 一期 `application-local-base.yml` 两处 `database` 确认为 3；二期 `application-local.yml` 已统一改 db3（2026-10-09），同步到 target/classes 重启；检查有无环境变量覆盖 |

## 七、不能直接调 dev 环境服务的原因

1. dev 服务注册的 IP 是 K8s 内网（192.168.x.x），本机不可达
2. dev 网关 `core-dev.voyah.cn` 可达（HTTP），能转发请求
3. **混合模式可行**：本地 project + dev OAuth（经代理 localhost:16200），前提是 local Redis database = **3**（与 dev K8s ConfigMap 一致），OAuth 把 token context 写 db3，本地 project 从 db3 读 → 校验通过
