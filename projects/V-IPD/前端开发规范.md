## 二、项目结构

### 2.1 多入口架构

```
src/
├── main.js             # → index.html   主应用（完整路由/菜单/布局）
├── subpage/main.js     # → subpage.html 子页面（独立 router/store/views）
├── api/                # API 封装（按服务分域）
│   ├── baseUrl.js      # ★ 路由分发核心
│   ├── platform/       # 一期平台 API
│   ├── pm/             # 一期 PM 业务 API
│   ├── cmf/ dvp/ experience/ metrics/  # 二期业务 API
│   └── esign/          # 电子签章
├── views/              # 页面（按业务域分）
├── business/           # 可复用业务组件（selector/dialog/panel）
├── components/         # 通用组件
├── store/              # Vuex
├── router/             # 路由（routes.js + utils.js 动态菜单）
├── locales/           # 四语翻译
├── constants/ directives/ filters/ mixins/ plugins/ utils/ assets/ mock/
```

**注意**：改 `business/` 或通用组件，需考虑主应用与 subpage 双入口同步。

### 2.2 API 路由分发（baseUrl.js）

前端按微服务前缀分发（经 vue proxy）：

| 前缀 | 目标 | 用途 |
|------|------|------|
| `/iform/<alias>/v3/**` | 一期各 iform 服务 | 平台能力（表单/流程/组织） |
| `/powerproject/v3` | provider-powerproject | 一期 PM 主业务 |
| `/pp-project/v3/api` | pp-project | 项目管理 |
| `/pp-timesheet/v3/api` | pp-timesheet | 工时 |
| `/pp-document/v3/api` | pp-document | 文档 |
| `/pp/<alias>/v1` | 二期 pp-* 服务 | 二期业务 |
| `/api` | esign（开发代理） | 电子签名 |

## 三、命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| Vue 组件文件 | PascalCase | `ProjectList.vue` |
| JS 文件 | camelCase | `projectApi.js` |
| 样式文件 | kebab-case | `project-list.scss` |
| 目录 | kebab-case | `project-detail/` |
| 变量 | camelCase | `projectId`, `userList` |
| 常量 | UPPER_SNAKE | `API_BASE_URL`, `MAX_FILE_SIZE` |
| 组件引用 | PascalCase ref | `<ProjectList ref="projectList" />` |
| Vuex action | `set<Module>` 或 `fetch<Module>` | `setUser`, `fetchProjectList` |

## 四、API 封装

### 4.1 统一 request

`src/utils/request.js`：配置 baseURL、超时、请求拦截（注入 Token）/响应拦截（401 跳转登录、统一错误处理）。

### 4.2 API 文件

- 按业务模块拆分，命名 `src/api/<域>/<对象>.js`
- 函数返回 Promise，命名以 `get`/`post`/`put`/`delete` 开头

```js
// src/api/pm/project.js
export function getProjectList(params) {
  return request({ url: '/pp-project/v3/api/project/list', method: 'get', params })
}
export function saveProject(data) {
  return request({ url: '/pp-project/v3/api/project/save', method: 'post', data })
}
```

## 五、路由

- 静态路由在 `src/router/routes.js`
- 动态菜单：`utils.js` 根据权限加载，`defaultUrl` **不带 `.vue` 后缀**（带后缀会被 catch 吞掉静默降级到 404）
- path 用 kebab-case
- 懒加载 `() => import('@/views/xxx.vue')`
- 守卫：`router.beforeEach` 处理 Token 检查、权限校验、页面标题

## 六、状态管理（Vuex）

- namespaced 模块：`store/modules/iform/`、`pm/`、`competitor/`、`rule/`
- 统一 Action → Mutation → State 流程
- 跨模块共享状态优先走 getter

## 七、组件规范

- SFC：`<template>` / `<script>` / `<style scoped>` 顺序
- Props 必须有类型 + default
- 禁止模板内复杂表达式（提取 computed 或方法）
- 大组件拆子组件
- Element UI 为主，Ant Design Vue 仅在特定模块（部分模块已用）
- 表格优先 VXE Table（新功能）；Handsontable 用于类 Excel 编辑场景；VTable 用于高性能大数据展示

## 八、样式

- `scoped` 防污染
- 预处理器：SCSS
- 全局变量 `src/styles/variables.scss`
- Element UI 主题变量覆盖在 `src/styles/element-variables.scss`

## 九、ESLint / Prettier

- ESLint 7.32 + `@vue/eslint-config-standard`
- **历史债**：406 个 error 未清，`lintOnSave` 设 warning 不阻塞
- `lint --fix` 会大面积改动，谨慎使用
- 提交前跑 `vue-cli-service lint`

## 十、构建与部署

### 10.1 构建

```powershell
# 必须 --openssl-legacy-provider + 8GB 堆（否则 OOM exit 134）
$env:NODE_OPTIONS = "--openssl-legacy-provider --max-old-space-size=8192"
node "node_modules/@vue/cli-service/bin/vue-cli-service.js" build --mode prod.cloud
```

### 10.2 启动

```powershell
cd powerprojectforjava-frontend
$env:NODE_OPTIONS = "--openssl-legacy-provider --max-old-space-size=8096"
node "node_modules/@vue/cli-service/bin/vue-cli-service.js" serve --open
# 端口 9528，首次编译 21000+ 模块需几分钟 + ~4GB 内存
```

### 10.3 内存策略（16GB 机器）

- 不要同时启动 12 个 Java 服务 + 前端首编译（会 OOM 全挂）
- 内存不足：先停 Java，等前端编译完（`http://localhost:9528/` 返回 200）再起 Java

### 10.4 vue.config.js proxy（已配置）

- `^/gateway/iform/<alias>/v3` → 一期 `localhost:<端口>`（剥整个前缀）
- `^/gateway/iform/pp/<alias>/v1` → 二期 `localhost:<端口>`（只剥 `/gateway/iform`，服务自带前缀）
- 兜底 `^/gateway` → `https://core-test.voyah.cn`
- `^/api` → e签宝
- `^/dhtmlx`（甘特导出）→ core-test

## 十一、常见坑

| 坑 | 解决 |
|----|------|
| `pnpm build` OOM exit 134 | 加 `--max-old-space-size=8192` |
| Node 17+ 报 `digital envelope routines::unsupported` | 加 `--openssl-legacy-provider`（webpack 老 loader 用了 OpenSSL 3 废弃的 MD4） |
| 菜单 `defaultUrl` 带 `.vue` 后缀静默 404 | 不带后缀 |
| dev 启动刷 400+ ESLint error 是噪音 | `lintOnSave` 降 warning |
| 无 lock 文件进 git | packageManager 声明 yarn@1.22.21，实际可用 pnpm + .npmrc |
| Authorization header 格式 | 前端用裸 JWT，不是 `Bearer ` 前缀 |
| 滑块验证码 ST 无法纯 API 登录 | 浏览器登录后抽 token |
