## 1. 整体架构

V-IPD 是岚图汽车的整车研发项目管理平台，覆盖产品研发域与工艺制造域。**一套前端 + 两代后端**：

```
┌──────────────────────────────────────────────────────────────┐
│  前端 powerprojectforjava-frontend (Vue 2.6, 端口 9528)        │
│  多入口: index.html(主应用) + subpage.html(子页面)              │
└───────────────────────────┬──────────────────────────────────┘
                            │ vue proxy /gateway/iform/** 剥前缀
        ┌───────────────────┼─────────────────────┐
        ▼                   ▼                     ▼
┌────────────────┐  ┌────────────────┐  ┌─────────────────────┐
│ 一期后端(5服务)  │  │ 二期后端(7服务) │  │ 外部: e签宝/飞书     │
│ iform 3.5.8    │  │ Spring Boot    │  │ /api → esignoss     │
│ Spring Cloud   │  │ 2.6 轻服务群    │  │ 后端直连飞书 OpenAPI  │
│ Hoxton + Netflix│  │ 18081-18087   │  └─────────────────────┘
└───────┬────────┘  └───────┬────────┘
        │                   │
        ▼                   ▼
┌──────────────────────────────────────────────────────────────┐
│                      基础设施                                  │
│ GaussDB(主业务库) │ MySQL(iform平台库) │ Redis db3 │ Nacos      │
│ RabbitMQ │ (Kafka/ES 一期引入，dev 关闭)                        │
└──────────────────────────────────────────────────────────────┘
```

**线上入口**：`https://core-test.voyah.cn/`（预发布），Spring Cloud Gateway 统一转发。

## 4. 配置管理

- **一期**：XML 多级数据源加载 `dataSource-{cp}-{dbType}-{active}.xml → ... → dataSource.xml`；共享配置在 `iform-basic-root/modules/basic-response/src/main/resources/config/`（application-local-base.yml 含 Redis/Ribbon/GatewayFilter 配置）
- **二期**：`application-{env}.yml` 直配，环境变量全覆盖（`${VAR:default}`），支持 Nacos import（`optional:nacos:...`）
- **Profile**：`local` / `dev` / `test` / `prod`
- **真实配置在 Nacos**：仓库里的 yml 大多是壳；改配置必须同步复制到 `target/classes` 才生效（jar 是旧构建打的）

## 5. 网关路由

线上：`/iform/<alias>/v3/**` → StripPrefix=3 → 对应服务（见 basis-gateway 的 application.yml）。

本地开发不走网关：vue.config.js 的 devServer.proxy 按服务拆分：
- 一期 `^/gateway/iform/<alias>/v3` → 剥整个前缀 → `localhost:<端口>`
- 二期 `^/gateway/iform/pp/<alias>/v1` → 只剥 `/gateway/iform` → `localhost:<端口>`（服务自带前缀）
- 兜底 `^/gateway` → `https://core-test.voyah.cn`；`^/api` → e签宝

## 6. 数据库

- **主业务库**：GaussDB（openGauss 内核，PostgreSQL 兼容）。测试环境 `10.82.45.158:8000` 库 `PowerProject6_20260512`；预发布 `10.82.45.6:8000` 库 `PowerProject6`。双节点 + `targetServerType=master`
- **共 607 张表**（dev 实测）：`extends_` 139（二期）、`pp_` 175（一期业务）、`act_` 25（Activiti）、`iform_` 213（平台）、其他 55
- **平台库**：MySQL `47.113.205.64:3306/iform_v357`（auth/desktop 表，仅一期，不在 GaussDB）
- **DDL 迁移**：无 Flyway/Liquibase，SQL 文件按日期命名（`ddl/20260509-xxx.sql`）手工执行
- 国产化适配：内置 Oracle/KingBase8/Dameng/Oscar/GaussDB/MySQL 驱动

## 7. 关键横切机制

| 机制 | 说明 |
|------|------|
| GatewayFilter | 校验请求带网关密钥 header；本地 vue proxy 直连会被拦（"非法请求"），local 配置 `client.gateway.disable: true` 放行 |
| Redis db | 本地必须用 db3（dev K8s ConfigMap `SPRING_REDIS_DATABASE=3`，OAuth 把 token context 写 db3），用其他 db 报 REQUEST_408 |
| Ribbon 静态路由 | local 下服务间 Feign 走 `listOfServers: localhost:<端口>` 直连 |
| iform-integration-layer | 二期服务复用一期平台能力的唯一桥梁：OAuthSdk/OrgSdk/FormSdk/MessageSdk/FileSdk/TodoSdk，内部密钥 `authorization.secret.inner` |
| 待办同步 | 业务事件 → RabbitMQ → 写 `pp_todo`/`pp_todo_done` → VHome 同步（`pp_vhome_todo_sync_log`） |

## 8. 两代后端的关系（重要）

- 一期大部分业务表单**不是硬编码**，走 iform 动态表单引擎（form-biz）+ BO 业务对象定义 + Activiti BPMN
- 二期是独立轻服务，**不依赖 iform 任何代码**，通过 integration-layer 的 Feign 调一期接口（认证、组织、表单、消息）
- 一期代码来自 iform 上游 SVN 单向同步，**本地对 iform-* 模块的改动会被上游覆盖**，定制代码必须收敛到 pp-* 模块
