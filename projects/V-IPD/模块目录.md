## 一、前端（powerprojectforjava-frontend）

```
src/
├── api/               # API 层（按服务分域）
│   ├── baseUrl.js     # ★ 路由分发核心（BASE_API/OAUTH2/PLATFORM/PM 各前缀）
│   ├── platform/      # 一期平台 API（auth/bo/bpmn/cat/codegen/data/desktop/form/org/job/...）
│   ├── pm/            # 一期 PM 业务 API
│   ├── cmf/ dvp/ experience/ metrics/  # 二期业务 API
│   └── esign/         # 电子签章
├── views/
│   ├── platform/      # 24 个平台管理模块（auth/bo/bpmn/cat/codegen/...）
│   ├── pm/            # ★ 一期项目管理（project/budget/createProject/plan/team/timesheet/document/notice）
│   ├── performance/   # 性能指标（vehicle/performance-target/parameter/analysis/overview）
│   ├── experience/    # 体验管理（case/pool/voc/search/system-config）
│   ├── dvp/           # DVP（detail/list/standardLib/config）
│   ├── competitor/    # 竞品（library/vehicle/mock）
│   ├── special-part/  # 专用件（process/permission/composables）
│   ├── modeling/      # CMF（basic/car/color/plan/platform）
│   ├── metrics/       # 指标看板（pea/overview/lib）
│   ├── application/ system/ saas/ roleFieldPerm/ demo/
├── business/          # 可复用业务组件（selector/dialog/panel，按 platform/bpmn/... 分域）
├── components/        # 通用组件
├── store/             # Vuex（modules: iform/pm/competitor/rule）
├── router/            # 路由（routes.js 静态 + utils.js 动态菜单）
├── locales/           # 四语翻译
├── subpage/ 入口      # 子页面独立应用（main.js + 独立 router/store）
```

**注意**：主应用 `src/main.js` 与子页面 `src/subpage/main.js` 是两个入口，公共组件改动需考虑两边同步。

## 二、一期后端（powerprojectforjava-backend，35 个顶层模块）

### 2.1 可运行服务（5 + 1）

| 服务 | 模块树 | 依赖闭包 |
|------|--------|---------|
| oauth | `iform-oauth-root/modules/oauth-server2` | basic/oauth 基座 |
| platform | `iform-provider-root/modules/provider-platform` | base/basic/api/model/provider-base |
| business | `iform-provider-root/modules/provider-business` | 同上 + form/bpmn 全家 |
| project | `pp-project-root`（model/biz/provider/api/client 五件套） | 依赖 form/bpmn/permission/rule/message-producer 的 client |
| document | `pp-document-root`（model/biz/provider/api/client 五件套） | 同上 |
| (gateway) | `iform-basis-root/modules/basis-gateway` | 本地开发不启动 |

### 2.2 平台框架层（上游 iform，本地改动会被覆盖，勿在此定制）

| 模块树 | 职责 |
|--------|------|
| `iform-base-root` | 基础设施（framework/service/web/datasource/quartz/seata/disruptor/elasticsearch...） |
| `iform-basic-root` | 微服务基座（config/discovery/feign/redis/swagger/i18n/validator/monitor/response） |
| `iform-api-root` | API 契约（base/bo/form/org） |
| `iform-model-root` | 数据模型（bo/file/form/org） |
| `iform-form-root` | 动态表单引擎（form-biz/bo-biz） |
| `iform-bpmn-root` + `iform-bpmnbase-root` + `iform-activiti-root` | 工作流（Activiti 5.23 定制 + bpmn 插件） |
| `iform-oauth-root` | OAuth2（含 oauth-server2） |
| `iform-permission-root` / `iform-rule-root` / `iform-report-root` / `iform-socket-root` | 权限/规则/报表/WS |
| `iform-common-root` / `iform-comp-*` / `iform-component-root` / `iform-message-*` | 公共/组件/消息 producer+consumer |
| `iform-starter-parent` | Spring Boot Starter 父工程（版本管理） |
| 其他（appcenter/skeleton/excessive/project/other/openapi/basis） | 应用中心/骨架/遗留 |

### 2.3 构建体系

- 根目录无聚合 POM；`build/build.xml`（ant）按 37 个 package-* target 分层构建
- `local.8081.install.bat` → `ant -Dprofile=local-8081 -Doption=all -Dcmd=install`
- Maven settings：`C:\Users\perso\.m2\settings-vipd.xml`，profile `voyah-profile`
- 打包产物：antrun 展开重组的 `xxx.jar + lib/` 结构（非 fat jar）

## 五、改代码落点速查

| 要改什么 | 去哪里 | 约束 |
|---------|--------|------|
| 一期项目管理业务逻辑 | `pp-project-root`（biz/provider） | 不要改 iform-* 模块 |
| 一期文档管理 | `pp-document-root` | 同上 |
| 平台能力（表单/流程引擎本身） | 原则上不改；确需改 → 提上游 or 定制副本 | 上游同步会覆盖 |
| 二期任一业务 | 对应 `pp-*-root` | 独立自治，无 iform 依赖 |
| 二期调一期平台能力 | 只通过 `iform-integration-layer` 的 SDK | 内部密钥鉴权 |
| 前端页面 | `src/views/<域>/` | API 封装进 `src/api/<域>/` |
| 前端公共业务组件 | `src/business/` | 注意 subpage 双入口同步 |
