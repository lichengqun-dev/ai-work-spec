# 知识索引 · ai-iteration-03-change-control

> **本 Skill 未实现（P2 阶段交付），因此暂无知识文件。**

渐进式披露机制要求：`references/` 目录默认**只加载本文件**，模型按本文件列出的「何时读取」
按需读取具体知识文件。这样默认注入量从"全部知识"降到"索引 + 1-3 个文件"。

## 实现时应补充的知识文件

按该 Skill 的实际需要建立，通常是以下几类：

| 类型 | 用途 | 例 |
|---|---|---|
| **范本** | 产出物的合格标准 | 详细设计章节的写法范本 |
| **规则细则** | 无法写进 `prompt.md` 的详细规则（太长） | 达梦分页的多种写法与选择依据 |
| **清单** | 需要逐项核对的列表 | 接口评审检查清单 |
| **历史案例** | 已踩过的坑 | 某次设计评审被驳回的原因 |

## 写法要求

每个文件都要在**本索引**里标明「何时读取」，而不是让模型自己判断。

反例：只列出文件名，不写何时读——模型要么全读（浪费预算），要么漏读（产出不达标）。

正例：`| 详细设计章节范本.md | 写功能详细设计时必读 |`

## 预算约束

单次执行按需加载不超过 **3 个文件、合计 1500 行**。超过说明知识文件该拆分或该精简。
