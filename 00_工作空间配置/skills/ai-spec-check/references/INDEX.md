## 什么时候该在本目录新增文件

当出现**只有这个 Skill 用得上**的知识时。例如：

- 新增检查项后，该检查项的判读细则
- 已确认的误报案例（"这类写法是合法的，不要报"）

**判据**：同域其他 Skill 会不会用到？会 → 放域级 `references/`。
共用知识在每个 Skill 下各存一份，是知识库腐化的典型起点——改一处忘另一处。
